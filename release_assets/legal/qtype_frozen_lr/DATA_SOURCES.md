The project prepared fixed splits, silver/relevance labels, negative examples and/or numeric pair features for training. These archives do not distribute the original questions, answers, context article bodies, supporting-fact records, training embeddings or candidate feature tables. The QType archive retains project-generated scalar probabilities, not source text. Dataset attribution does not relicense HotpotQA under Apache-2.0; its original license continues to apply to the dataset. The model license covers the supplied parameters and project metadata; training alone is not represented as automatically relicensing weights under CC BY-SA.
