## 如何使用

1. **先看核心結果**：每份檔案第一節保留 PR@1、95% CI、正確數、Bridge/Comparison 與候選召回率。
2. **再看對照／消融**：將同候選排序增益與跨候選系統比較分開，避免錯誤因果解讀。
3. **需要稽核時再展開**：原始全部方法與配對統計完整附在末尾，不犧牲可追溯性。

## 不能從這些結果推論的事情

- Official Dev **沒有** R0 同候選比較，不能把對單跳 baseline 的差距說成 R5 排序器的單獨貢獻。
